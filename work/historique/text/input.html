Ce qui fonctionne aujourd’hui

Le dialogue utilise Qwen3-0.6B en local. Les adaptations françaises sont activées après validation. L’historique récent accompagne chaque demande ; les échanges les plus anciens peuvent sortir de sa fenêtre de mémoire.

Les conversations sont conservées dans ce navigateur. « Nouvelle conversation » remet le contexte à zéro. La syntaxe JSON est contrôlée ; cela ne garantit pas la justesse des réponses.
