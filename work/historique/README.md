# Scripts historiques

Archives des préparations, rapports et recettes écrits pendant la conversation. Ne pas les relancer tels quels : beaucoup écrivent à l'ancien emplacement plat de `outputs/`, supposent d'anciens chemins relatifs (`work/text/...`) ou relancent des entraînements. Les chemins absolus vers le dossier de conversation ont été corrigés le 18 octobre 2026 (`fix_paths.py`), le rangement fait par `tidy.py`, la comparaison aux originaux par `cmp_originaux.py`.

Pour retrouver une méthode, lire le script ; pour l'exécuter, le copier d'abord vers le projet concerné et adapter ses sorties.
